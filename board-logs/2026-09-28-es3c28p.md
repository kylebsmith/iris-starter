What the sketches did on the board of the 2026-09-25 log, with every copy of
`iris.h` the library's header as tagged `v0.3.0`. Serial output is copied as
the board printed it, from the moment the computer opened the port. Nothing
here needed a person at the board: every sketch was uploaded and read over
USB, and the one check that moves the sensor was decided at rest (section 5).

PASS: the scan starts on the board's socket, where the BNO055 answers at
0x28 beside the board's audio codec (0x18) and touch controller (0x38); the
touch controller and codec answering there identify the board, and nothing
else is printed: the sketch skips every pair that uses one of the board's
wired pins, among them GPIO 8 and 9 of the `Wire.begin()` default, where the
2026-09-25 scan got an answer at 0x08, and nothing answered on the
expansion socket's free pins, which it scans instead. The device at 0x77
gives chip identifier 0x61 in register 0xD0 and variant 0x00 in register
0xF0: a Bosch BME680.

## 5. `heading.h`

`heading.h` assumes that the BNO055's fusion quaternion q turns the board's
frame into the Earth's, so that q* v q turns an Earth direction into the
board's. At rest the sensor lies tilted about 10 degrees about its own x
axis. The gravity vector the sensor reports, scaled to length 1 (UP),
matches q* (0, 0, 1) q, the Earth's vertical turned into the board's frame
the way `heading.h` turns FRONT, to the third decimal, the sign of the
tilt's 0.17 included; turned the other way, that component would read +0.17.
After `f`, FRONT is (1.000, 0.000, 0.002), the board's x axis laid flat, and
UP . FRONT is 0.000. A check sketch that is not in the kit printed these
lines at rest, first before `f` (its first reading line comes before the
sensor's first reading; `cal` is the fusion's calibration: system,
gyroscope, accelerometer, magnetometer):

```

UP  0.000  0.000  0.000  FRONT  1.000  0.000  0.000  dot  0.000  q*z  0.000  0.000  1.000  cal 0000
UP  0.002 -0.170 -0.985  FRONT  1.000  0.027 -0.002  dot -0.000  q*z  0.002 -0.171 -0.985  cal 0000
UP  0.002 -0.170 -0.985  FRONT  1.000  0.027 -0.002  dot -0.000  q*z  0.002 -0.171 -0.985  cal 0000
```

and then after it:

The check sketch, beside a copy of `heading.h`:

```cpp
/* heading_check: UP and FRONT from heading.h, and UP . FRONT, four times a
   second. FRONT is horizontal in the Earth's frame and UP vertical, so their
   dot product is 0 at every pose exactly when heading.h turns FRONT the right
   way; turned the other way it is 0 only when the board is level. f sets the
   front. Also q* (0,0,1) q beside UP, and the fusion's calibration. */
#include <Wire.h>
#include <Adafruit_BNO055.h>
#include "heading.h"
static Adafruit_BNO055 bno = Adafruit_BNO055(55, 0x28, &Wire);
static Heading heading;
void setup() {
  Serial.begin(115200);
  while (!Serial && millis() < 20000) delay(10);
  delay(200);
  Wire.begin(16, 15);
  if (!bno.begin()) { bno = Adafruit_BNO055(55, 0x29, &Wire); }
  if (!bno.begin()) { Serial.println("no BNO055"); for (;;) delay(1000); }
  Serial.println("heading_check ready");
}
void loop() {
  if (Serial.available() && Serial.read() == 'f')
    Serial.println(heading_set_front(heading, bno) ? "front set" : "front not set: too near vertical");
  float in[6];
  heading_read(heading, bno, in);
  const float dot = in[0] * in[3] + in[1] * in[4] + in[2] * in[5];
  imu::Vector<3> uq = bno.getQuat().conjugate().rotateVector(imu::Vector<3>(0.0, 0.0, 1.0));
  uint8_t s, g, a, m;
  bno.getCalibration(&s, &g, &a, &m);
  Serial.printf("UP %6.3f %6.3f %6.3f  FRONT %6.3f %6.3f %6.3f  dot %6.3f  q*z %6.3f %6.3f %6.3f  cal %u%u%u%u\n",
                in[0], in[1], in[2], in[3], in[4], in[5], dot, uq.x(), uq.y(), uq.z(), s, g, a, m);
  delay(250);
}
```
